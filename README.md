## 启动

在本目录运行：

```text
python -m http.server 8310 --bind 127.0.0.1
```

打开 http://127.0.0.1:8310/index.html 。必须使用 HTTP，场景 SVG 通过 fetch 加载，不建议 file://。如果端口已占用，复用已有服务或改端口，不要重复启动。

## 文件

- index.html：桌面评审工作台、脚本/样式加载。
- js/screens.js：23 个路由定义、页面结构、中英文文案。包含2个评审专用路由；左树计数25包含配网成功/超时状态入口，重命名/移除为弹层。
- js/handoff.js：逐页工程说明覆盖层，仅用于右侧说明，不实现业务。
- js/app.js：原型状态、模拟交互、动效生命周期。
- css/：基础样式、产品图形动效、居家场景、关于页。
- assets/：本地 SVG 产品和场景。保留的旧素材不等于当前页面使用。
- js/confetti.browser.min.js + confetti.LICENSE：撒花库及随附许可证。
- Sofia Sans 当前通过 Google Fonts 远程加载；离线打包、字体许可证与第三方资源清单需发布前核验。

## 演示与限制

默认进入我的设备；左树可直接选各状态。搜索无结果演示使用 `?search-result=timeout#/add/search`。蓝牙与配网默认约3秒模拟成功；失败入口可预览退水、重试；这些时间不是协议超时。

左树、右侧、交互日志、重置和语言按钮仅用于评审。正式 App 不包含工作台。
所有连接/权限/扫描/网络/控制均非真实通信；状态只在内存，刷新重置。按型号模拟设备、连接互斥、固定 SSID、立即成功的控制不能直接作为生产实现。
